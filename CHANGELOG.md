# Changelog

## 1.0.0

- Initial release: `<AutoSkeleton loading>` generates a shimmer skeleton from the real DOM of its children
  (text lines, media, form controls, painted boxes and container surfaces), with shimmer/pulse/none
  animations, theming via props or CSS variables, RTL support, `inert` + `aria-busy` accessibility,
  automatic re-measuring, SSR and React 16.14 – 19 support.
- `collectSkeletonBlocks(element)` low-level measuring API.
